# Scrapy Parser PEP

Асинхронный парсер документов PEP (Python Enhancement Proposals) на базе фреймворка Scrapy.

## Описание

Проект собирает информацию о всех PEP с сайта [peps.python.org](https://peps.python.org/) и сохраняет её в два CSV-файла:

1. **Список всех PEP** — номер, название и статус каждого документа.
2. **Сводка по статусам** — сколько документов найдено в каждом статусе, плюс итоговое количество.

## Технологии

- Python 3.9+
- [Scrapy](https://scrapy.org/) — фреймворк для асинхронного парсинга
- `csv` — стандартная библиотека для записи сводки
